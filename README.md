# 🩺 Breast Cancer Data Analysis  

 Project Overview  
This project focuses on analyzing a dataset of **breast cancer patients** who underwent different surgical procedures. The analysis was carried out to identify key health patterns, evaluate hospital performance, and provide insights that can guide evidence-based decision-making in cancer management.  


Objectives  
1. Identify which **surgery type** recorded the highest number of patients.  
2. Analyze the **distribution of patient outcomes** (alive, deceased, not specified).  
3. Examine the **percentage distribution** across different **cancer stages (I–III)**.  
4. Compute **key performance indicators (KPIs)** such as total cases, death rate, and surgery counts.  
5. Highlight insights to support the hospital’s Chief Medical Director (CMD) in improving awareness and preventive strategies.  


 Dataset Description  
The dataset includes:  
- Patient demographic data (age, gender)  
- Cancer stages (I, II, III)  
- Surgery types  
- Survival status  
- Insurance and year of surgery  

Sensitive patient identifiers were removed to maintain confidentiality.  



 Tools & Technologies Used  
- **SQL** – Data cleaning and preparation  
- **Tableau** – Dashboard creation and visualization  
- **Statistical Analysis** – KPI computation and summary insights  


 Analysis Summary  

**Surgery Type Distribution**  
- The **“Other”** category recorded the highest number of patients (**105**).  
- Suggests a shift toward specialized or alternative surgical procedures.  

** Patient Status Distribution**  
- **Alive:** 255 patients (≈74%)  
- **Deceased:** 66 patients (≈19%)  
- **Not Specified:** 13 patients (≈4%)  
- Indicates a strong survival rate, suggesting effective treatments or early detection.  

**Cancer Stage Distribution**  
- **Stage I:** 19.16%  
- **Stage II:** 56.59%  
- **Stage III:** 24.25%  
- Most patients were diagnosed at **Stage II**, showing the need for **earlier screening and awareness**.  

 Dashboard Overview  
Interactive dashboard created in **Tableau** visualizing:  
- Surgery type by patient count  
- Patient survival distribution  
- Cancer stage analysis  
- Key performance indicators (KPIs)  

 View Tableau Dashboard - https://public.tableau.com/app/profile/emediong.kingsley/viz/cancerdashboard_17603586814260/Dashboard1

 Key Insights  
- The hospital records a strong **74% survival rate** across cases.  
- A majority of patients are diagnosed at **Stage II**, emphasizing the need for **early detection programs**.  
- Continuous tracking of KPIs like **death rate** and **surgery outcomes** can guide management’s strategic decisions.  

 Recommendations  
- Strengthen **community-based screening** to detect cases earlier.  
- Improve **data entry systems** to reduce “Not Specified” status cases.  
- Expand **awareness campaigns** targeting women aged 35–55.
